# 首次公开 Beta 版本与验证边界

首个公开 Beta 为 **0.19.4 Build 35**，公开源码和发行入口为 [MeloCanvas-Public](https://github.com/lxiaodong681-lab/MeloCanvas-Public)。它接续维护者验收的 Build 34，修正公开项目 / 反馈地址与版本说明，补充首次通知提示及锁屏常见问题。播放、推荐、目录导入等功能沿用 Build 34。

源码快照不带旧 Git 历史、提交者资料、设备截图、实验日志、历史 APK、私有开发报告或本机配置。自有代码及明确标注 MIT 的素材采用 MIT；OC 立绘与八态贴纸采用专用许可，仅允许随音绘使用和分发，其他用途须经维护者许可。第三方许可及既有 CC0 授权保留。源码测试使用合成账号及歌词，主题回归使用固定源码夹具。

原有 20 项来源不明素材已通过替换 18 项、排除 2 个上游收款码处理；[素材清单](../release/asset-audit.json) 的 93 项均有来源及许可记录。替换素材可由脚本重现，这不构成对原图的追溯授权。

8 个 npm 缺失文本、原生组件声明、Maven 源码版权、Expo / Kotlin NOTICE、MPL 域名后缀表源码及 LGPL 材料已补入审查集合。应用内可离线查阅；CI 对实际包版本、二进制摘要和许可文件逐项核对。Install Referrer 已从产品依赖路径移除，需由实际清单和 DEX 检查确认。详细范围见 [分发审核](distribution-review.md)，替换构建见 [LGPL 说明](lgpl-distribution.md)。

每个发行包必须具备以下材料与检查，不能套用上一提交的通过结果：

1. 同一最终提交的 CI 全部通过，并将普通签名 APK、依赖清单、无历史源码快照、LGPL / MPL 对应源码和摘要绑定交付。带验证类的 LGPL 证明 APK 不是用户验收包。
2. 明确真机验收范围与未覆盖场景。维护者使用 Build 34 后确认发行，并在 iQOO 13 / Android 15 上确认：开启音绘的系统“锁屏通知”后音乐卡片正常显示。这是用户反馈，不代表所有设备或全部功能逐项通过；Build 35 新增引导的自动化检查也不能代替实际设备显示验证。
3. 对最终包核验权限、遥测 / 非必要 SDK 排除、签名与依赖材料；持续收集实际网络和厂商后台策略问题。未完成所有机型、长期播放、蓝牙 / 来电组合或完整网络抓包覆盖，不宣传全面隐私认证。

下载以 [公开 Releases](https://github.com/lxiaodong681-lab/MeloCanvas-Public/releases) 中材料齐全的预发布条目为准。原有私有开发库和旧历史保留，公开库从白名单源码创建独立根提交；原始反馈、备份和设备截图不公开。通知与锁屏排查见 [安装指南](../INSTALL.md)，新增网络来源和功能限制见 [导入与心动推荐](music-discovery.md)。
