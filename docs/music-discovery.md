# 导入与心动推荐（Beta 候选）

本页描述 0.19.4 Build 35 的导入与心动推荐行为。功能仍处于 Beta，平台接口、内容匹配及机型兼容性可能变化；具体发行材料和验证范围见 [版本说明](public-beta-status.md)。

## 播放体验

再次点击正在播放的同一歌单条目或队列条目会保持当前位置，暂停时续播。队列中的另一份重复条目仍是一次新的选曲。顺序、单曲循环和随机播放沿用原生保存的音乐偏好，换歌单、切换听视频、重启恢复后继续保留；临时私人 FM 的顺序不会覆盖这项偏好。

## 心动推荐第一版

在“私人 FM”中点击“按我的歌单找一批”，先显示候选，再确认开始播放。汇总本机所有已保存的音乐歌单，包括 B 站收藏中已整理为音乐的条目、已匹配的外部条目，以及外部歌单中仍待匹配的歌曲元数据。明确归为非歌曲或未知类型的 B 站导入条目不作歌曲种子。

各歌单均分总权重 10，喜欢总权重上限 3，最近 100 条真实音乐播放记录总权重上限 0.5；同一歌单的重复条目不重复加权。搜索历史不参与。UP 主姓名不当作歌手：有原平台歌手字段时使用该字段，否则用歌曲标题关键词。偏好只在本机计算，不保存新的远程画像。

每次随机抽取最多三个不同关键词，复用现有 B 站搜索通道，去掉本机已知或不感兴趣的 BV、重复 BV、非音乐分区和超过 15 分钟的候选，最多读取十二个详情，随机排列后供试听。网络限制会停止本轮；取消或离开后迟到结果不会开始播放。它不验证歌手身份、曲风或是否为原版，也没有网易云的曲库、协同过滤模型和音频特征。

开始后沿用私人 FM 的临时队列与恢复机制，后续补充合格的本机音乐；没有自动无限在线推荐。候选用尽会停止，可重新查找。每日推荐仍是本地精选；初次空列表现在会在同一天新增合格音乐后自动填充，已有非空日快照保持稳定。

## 平台导入范围

只读取公开目录中的歌曲名、歌手、专辑、时长和原曲身份，再由用户核对 B 站匹配版本；不读取这些平台的音频，也不迁移登录会话。

| 来源 | 当前新增能力和限制 |
| --- | --- |
| 酷我 | `kuwo.cn/playlist_detail/…` 或 `m.kuwo.cn/newh5app/playlist_detail/…` 完整链接；读取全部分页并核对身份及总数。 |
| 汽水 | `qishui.com/share/playlist?playlist_id=…` 或 `music.douyin.com/qishui/share/playlist?playlist_id=…`；读取汽水歌曲目录，不把抖音原声收藏总量当成歌曲数。 |
| 酷狗 | `www.kugou.com/songlist/gcid_…/` 或 `m.kugou.com/songlist/gcid_…/`；公开页面可能只返回十首预览，保留真实总数并明确报未读完整，不声称全部导入。登录云歌单和其他分享格式尚未接入。 |

新增来源暂不自动跳转短链。可先用浏览器打开分享链接，再复制完整地址。每轮最多 50 页、累计 8 MiB、5,000 条；缺页、相同页循环、曲数变化或身份不符都不会标记完整。原目录与重复项顺序保留。已有数据库会事务性升级并核对外键；升级失败保留旧数据。含新平台条目的备份不能保证被旧版本读取。

目录适配参考 MIT 许可的 [PlaylistOut a90e1a7f](https://github.com/LengxiQwQ/playlistout/tree/a90e1a7f0a32f020c1e03829570673f993669c63)，版权声明已保留；未引入第三方托管解析服务器。公开样例网络验证记录保留在私有审查材料中，不把真人歌单内容放进公开测试夹具。

## 网易云实现调研

网易云推荐工程师的 [公开技术分享](https://www.infoq.cn/article/caqErFHGX7S1LLX1Y2wg) 描述了召回、排序、多模态特征和实时反馈；[公开研究论文](https://arxiv.org/abs/2108.13592) 也说明其在线系统使用训练出的用户兴趣模型。由此可判断核心能力依赖服务端曲库、模型和用户反馈数据，不能从本机安装目录直接移植。公开资料未给出当前“心动模式”的完整专有算法，本项目不声称复制了该算法。桌面安装检查只读取了程序版本与安装资源，未读取账号、Cookie 或私人缓存，也未复制网易云客户端代码。
